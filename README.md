# WebGPT

**WebGPT** is a lightweight, open-source WebView-based Android app for accessing [ChatGPT](https://chatgpt.com).

It is designed for users who face compatibility issues with the official ChatGPT app or prefer a minimal and fast interface. The project is released under the GNU GPL-3.0.

---

## ✨ Features

* Ultra-light WebView wrapper (APK size under 150 KB)
* Automatic light/dark theme based on the system
* No analytics, no tracking, no background services
* External browser used for all non-ChatGPT URLs

---

## ⚠️ Limitations

*   Does not support login via Google, Apple, or Microsoft accounts.

## 📥 Installation

1. Download the latest APK from the [Releases page](https://github.com/qomarhsn/WebGPT/releases/latest) (find the `.apk` in the **Assets** section).
2. Open the downloaded file on your device.
3. Allow installation from your browser/file manager if prompted.
4. Launch **WebGPT** and sign in to ChatGPT.
